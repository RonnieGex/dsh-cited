# Curl verification

The script executes `curl --silent --show-error --max-time 20 --config - --write-out '\n%{http_code}'` twice, with JSON-RPC tools/list supplied in stdin configuration. Authorization is supplied only for the first request, through stdin. The token is never printed or placed in a process command line.

- No token in response output.
