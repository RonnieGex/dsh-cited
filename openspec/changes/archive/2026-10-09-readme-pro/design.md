# Design

## Decisions

1. Run `scripts/render-readme-graphics.mjs` with Node 24. Resolve Playwright from the existing Cited checkout selected by `CITED_REPO` using `createRequire`; do not add npm dependencies. Document the built-in sibling default and prerequisite explicitly.
2. Store HTML templates and minimal shared rendering helpers in `scripts/readme-graphics/`. Copy Outfit WOFF2 files and OFL text into `docs/fonts/outfit/` and authentic dark/light Katalis flame files into `docs/brand/` from the supplied public brand directory. Keep a provenance note. Reuse concepts from the existing renderer, without copying application-specific rendering code.
3. Emit six PNGs: `readme-banner-light.png`, `readme-banner-dark.png`, `how-it-works-light.png`, `how-it-works-dark.png`, `real-answer-light.png`, `real-answer-dark.png` in `docs/images/`. Each README references these through `<picture>` with dark media source, light fallback and descriptive alt text. Keep total PNG size below 3 MB. The graphics share English content across translations as explicitly requested.
4. The banner says "Cited inside DeepSeek Harness" and attributes Katalis with its authentic flame. The installation flow shows exactly three numbered stages: paste the repository link in Plugins > Add plugin, set url/token, ask and receive [1]. The answer graphic presents a readable terminal excerpt of the new saved run, not an invented answer. Full plain text remains linked beside it.
5. Capture through `scripts/capture-readme-evidence.mjs` using the source CLI 0.1.6-alpha.2, a fresh `mkdtemp` temporary `DSH_HOME`, the existing `DEEPSEEK_API_KEY` environment value and explicit headless profile. Use the local capture endpoint at port 3240 with its token read from a file without printing it. Capture fails closed when that endpoint or another prerequisite is unavailable; it does not start a server automatically. `docs/readme-assets.md` documents preparing an isolated public-sample server using the existing gate's seed/start technique and selecting its URL, token file and sample database through `CITED_CAPTURE_URL`, `CITED_TOKEN_FILE` and `CITED_CAPTURE_DATABASE` before retrying. The integration gate selects the existing `community-cap` checkout through `CITED_REPO`, because that checkout contains the required seed script. Never use the desktop profile, never rewrite global agent config and never copy credential contents into evidence.
6. Save sanitized public text evidence under `docs/evidence/`, including date, actual harness version, command with placeholders, prompt, actual `cited_search` arguments, returned passages and final cited answer. A model failure is a failed validation; it does not justify synthesizing an answer. The renderer reads saved evidence as its single answer source.
7. Keep all translation sections complete. Explicitly describe the timeout default, search bounds, ask persistence with sessionId, empty configuration behavior and failure behavior from source. Explain that the secret role hides the field from browser readback; do not claim encryption at rest or complete model-cost freedom for server configurations that use embeddings.
8. Present compatibility with dated evidence levels: harness model/tool execution, Claude Code MCP listing, Codex MCP listing and Cursor documented only. Existing assignment-backed claims are labeled as prior evidence; new claims require new local records. Desktop click-through and model-backed `cited_ask` remain unverified unless independently exercised without desktop control.
9. Add `.github/workflows/ci.yml` for push and pull requests: Node 24, `npm install --ignore-scripts --package-lock=false`, portable client/module/package/tool/documentation unit tests, build equivalence and gitleaks. Existing exact development host dependency versions remain unchanged. Explicitly select test files that do not require a sibling host checkout. The real Loader composition and integration gate run locally against an actual host and Cited checkout; CI does not claim to execute those external integrations.
10. Add contract tests before implementation for required sections, local theme assets, links, dependency-range consistency, evidence correspondence and prohibited typography. Renderer Playwright validation checks font readiness, local asset loading, unresolved placeholders and element overflow in both themes. Visual inspection confirms real flame and readable terminal output. There is no product frontend; rendering checks are the applicable browser E2E coverage.
11. Preserve `src/` and `lib/`. Report plugin database non-ownership explicitly; count/hash sample documents/passages and conversation state before/after search-based validation to demonstrate no persistence mutation. Run `scripts/check-readme-http.mjs` to execute reproducible authenticated and missing-token curl checks. Supply the bearer to curl over stdin, never in command-line arguments or logged output, and save sanitized HTTP outcomes in `docs/evidence/mcp-http.json`.
12. Update docs/readme-assets.md and docs/project-manual.md with exact reproducible commands and remaining prerequisites. Store all lifecycle reports beside these artifacts, then archive them together before committing and opening a PR to main. Do not merge the PR.
13. Keep `ai-specs/agents/` as the single tracked source of agent contracts. Ignore `.claude/agents/`, `.codex/agents/` and `.cursor/agents/` in Git and recreate these local links after cloning with `scripts/link-agent-contracts.mjs`: directory junctions on Windows, relative directory symbolic links on Linux. Document the command in the project manual. The script must preserve an existing correct link and refuse to replace a real directory or an incorrect link. Use `docs/base-standards.md` as this repository's adapted standards source; do not reference a nonexistent `docs/katalis-sdd-standard.md`.

## Exclusions

Tasks B and C, desktop automation, public deployment, new runtime dependencies, runtime tool behavior changes and modifications to other repositories are excluded. External model nondeterminism requires truthful observed evidence, not a fixed fabricated answer.
